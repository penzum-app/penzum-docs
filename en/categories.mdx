---
title: Expense Categories
description: Classifying expenses by category
---

Every expense can be assigned a category, which helps with overview and reporting.

## Available categories

| Category | Examples |
|---|---|
| Office supplies, printing | Paper, toner, office supplies |
| IT | Laptop, software, subscriptions |
| Phone, internet | Mobile bill, internet |
| Vehicle | Fuel, parking, service |
| Travel, accommodation | Train, flight, hotel |
| Marketing, advertising | Ads, website |
| Accountant, consulting | Professional fees |
| Bank, financial fees | Account maintenance, transaction fees |
| Other business expense | Everything else |

## Changing a category

Any expense's category can be changed later — click the expense row and select the new category.
