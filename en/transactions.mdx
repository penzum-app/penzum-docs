---
title: Bank Transactions
description: Managing transactions imported from your bank account
---

Transactions from a connected bank account can be viewed on the **Bank** page.

## Categorization

Every transaction can be assigned a category — the same categories used for expenses. Categories can be changed later.

## Transaction types

| Type | Handling |
|---|---|
| Incoming payment | Can be matched to an invoice, does not automatically become income |
| Outgoing payment | Can be matched to an existing expense, or you can create an expense from it |
| Bank fee | If the description points to a bank fee (for example an account-keeping fee), it gets a bank fee category; you can create the expense from the item |

## Sync frequency

Transactions are refreshed once a day (a subscription feature); the provider does not guarantee the most recent data. The last sync time is shown at the top of the Bank page.
